# 生产依赖清单（版本已锁定）
#
# 为什么必须写死版本号：
#   1. 本项目是「无人值守跑在 GitHub Actions 上」的机器人，依赖一旦被上游
#      悄悄升级（哪怕只是 patch），行为变化只有等出事才知道 —— 而那时
#      推送已经发到群里了。锁定版本 = 让 CI 的行为可复现。
#   2. 不锁版本时 pip 每次都可能装到不同版本，线上失败无法在本地重现。
#   3. 升级必须是一次显式动作：改这里的版本号 → 跑完整测试 → 再合并。
#
# 升级流程：
#   python -m pip install -U google-genai requests
#   python tests/run_all.py            # 必须全绿
#   python scripts/smoke_run.py        # 两个冒烟场景都要过
#   然后把新版本号写回本文件。
# =============================================================================
